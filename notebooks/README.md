# Notebooks Folder

Drop the analysis notebook here (for example `screen_time_sleep_analysis.ipynb`).

It should be the notebook that:

1. Loads and cleans the survey data
2. Fits the SLR and MLR models (statsmodels)
3. Produces the diagnostics: residual plots, Q-Q plot, Cook's Distance
4. Runs the MCAR / MAR / MNAR missing-data sensitivity analysis
5. Reports the final result (R-squared < 1.1%, p = 0.58)

Tip: restart the kernel and run all cells top to bottom before committing, so the outputs a visitor sees are in order.

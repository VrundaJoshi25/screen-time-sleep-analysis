# Data Folder

Drop the survey CSV here (for example `survey_responses.csv`).

## BEFORE COMMITTING: anonymize

This survey was filled in by real classmates. The published dataset must not identify anyone.

- Remove: names, roll numbers, emails, phone numbers, exact ages if small subgroups make people identifiable
- Remove or truncate: free-text answers that could reveal identity
- Keep only the analysis columns: screen time, sleep duration, workload, caffeine, and the stratum label

If in doubt, publish a smaller, safer set of columns.
